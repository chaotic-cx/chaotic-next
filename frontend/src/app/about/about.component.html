Build infrastructure

Most packages build automatically from their AUR source. Some exceptions live in our package repository.

The main node runs in Hetzner's Finnish datacenter on an EX44, with hardware from Garuda Linux.

Get in touch

For questions and support, use our issue trackers or the Telegram group. For private matters, pick one of these channels.

Open an issue for enhancements, database corruptions and other requests. Report build bugs to the AUR package maintainers.

Mirrors

The mirror list shows every mirror and its status. We distribute files with Syncthing.

To host a mirror yourself, contact us through any of the channels above.
